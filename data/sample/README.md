# Sample data

This folder contains a small random sample (about 1,000 orders and all their related rows)
of the
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
It was created with `pipeline make-sample` and is meant for tests, CI and demos.
